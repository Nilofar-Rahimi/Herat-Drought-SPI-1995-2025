# Herat Drought Monitoring Dataset (SPI: 1995–2025)
This repository contains a processed 31-year meteorological drought dataset (1995–2025) for Herat and Western Afghanistan, derived from NASA POWER gridded precipitation data.
### Columns Description:
- LAT / LON: Geographic coordinates (WGS 1984)
- YEAR: Observation year (1995–2025)
- ANN: Annual precipitation sum (mm)
- Mean / SD: 31-year long-term mean and standard deviation per grid point
- Alpha / Beta: Fitted Gamma distribution shape and scale parameters
- SPI: Standardized Precipitation Index values (ready for interpolation in ArcMap/QGIS)
